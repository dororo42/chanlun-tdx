## 1. 相对方向（L1115-1147 `相对方向.分析`）

比较前区间(前高,前低)与后区间(后高,后低)：
- 前==后 → `同`
- 前高>后高 且 前低>后低：前低==后高 → `衔接向下`；前低>后高 → `向下缺口`；否则 `向下`
- 前高<后高 且 前低<后低：前高==后低 → `衔接向上`；前高<后低 → `向上缺口`；否则 `向上`
- 前高≥后高 且 前低≤后低 → `顺`（后包含前）
- 前高≤后高 且 前低≥后低 → `逆`（前包含后）

## 2. K 线合并（L3382-3433 `_兼并`、L3436-3517 `分析`）

- 新普K 与最后一根缠K 比较：无包含 → 新建缠K，`结构 = 下(关系向下) / 上(其余)`；
- 有包含（顺/逆/同）→ 合并进当前缠K：
  - 取值方向看 **前前缠K vs 当前缠K** 的关系：向下 → 取 min，否则取 max（标准缠论）；
  - 高=max/min(高)，低=max/min(低)；时间戳/标的K线更新为新普K；原始结束序号=新普K序号。
- 合并后取最后三根缠K `分型结构.分析(左,中,右)`：
  - 左中、中右 均为向上族（向上/向上缺口/衔接向上）→ `上`
  - 左中向上族 + 中右向下族 → `顶`（中.分型=顶，特征值=中.高；同时 右.分型=底，右.分型特征值=右.低）
  - 左中向下族 + 中右向上族 → `底`
  - 左中向下族 + 中右向下族 → `下`
  - 默认参数下 `可以逆序包含=False`（合并后不应出现 顺/逆，出现即异常）。

## 3. 笔（L4772-4892 `笔.分析`，默认配置：笔弱化=False、笔次级成笔=False、笔内元素数量=5、笔内相同终点取舍=False）

输入为"新确认分型"（每次 K 更新都会产出以最后三缠K为骨架的分型，但只有 顶/底 进入笔分析）：

1. 分型序列为空 → 直接收纳首个 顶/底 分型。
2. 上一分型与当前分型**结构不同**（顶底交替）：
   - `基础序列` = 缠K[之前分型.中 .. 当前分型.中]（含两端）；
   - 数量 ≥ 5 时：
     - 若 起点 分型的中不是该区间**实际极值缠K**（顶→底时为实际最高，底→顶时为实际最低；
       同值取时间戳最早者）→ 以实际极值处构造新分型递归（先修起点，再处理当前）；
     - 终点校验：顶→底时 当前分型.中 必须 == 区间实际最低缠K（同值取首/末按取舍配置），且方向关系匹配 → **添加新笔**（文=之前分型, 武=当前分型）；
     - 不满足 → 不成笔，尝试 `当前分型.右` 起的分型（跳过）。
   - 数量 < 5 → 不成笔，同样跳到 `当前分型.右`。
3. **结构相同**（顶后更高顶 / 底后更低底）→ 弹出旧分型/旧笔，在区间内找实际反极值重建中间笔，并"事后修复错过的笔"；
   若未创新极值 → 忽略当前分型。
4. 笔有效还要求 `文.左`、`文.右` 存在（L4764：`武.左 is None or 武.右 is None → 有效性=False`）。

## 4. 线段（L4997-5202 特征序列 + L5236+ 线段）

特征序列 = 与线段**反向**的笔序列，元素高低取笔的 文/武 分型特征值范围：

- `静态分析`（L5135-5187）逐笔扫描：
  - 与线段同向的笔：若特征序列 ≥3 且末三个特征已构成顶分型（向上段）且当前笔高 > 分型中高 → 末两特征替换为 fake（**分型替换**）；否则跳过；
  - 反向笔：与上一特征比较，关系 ∈ {顺,同}（普通四象 小阳/少阴）或 ∈ {顺,逆,同}（带缺口四象 老阳/老阴 且未开"忽视"开关）→ **合并**进上一特征；否则新建特征元素。
- `四象`（L5361）：段的前一缺口存在 → 老阳（上）/老阴（下），否则小阳/少阴。
- `特征分型终结`（L5314）：特征序列 ≥3 且末三特征构成 顶（向上段）/底（向下段）→ 线段终结。
- 线段终结后新段起点 = 特征分型的中（特征.文）。

> 移植采用**批处理等价实现**：对笔序列整体做特征序列划分 + 缺口两情形处理，
> 以夹具输出对齐（线段端点序列 100% 一致为通过标准）。

## 5. 中枢（L6513-6955 `中枢.分析`，批处理语义）

对线序列（笔中枢=笔序列，段中枢=线段序列）递归：

1. 找首个三线组：连续三线 `基础检查` = 相邻连续 且 左vs右 关系 ∈ {向下,向上,顺,逆,同}（**非缺口/非衔接**）；
   - 跳过 序号==0 起头的中枢（`跳过首部=True`）；
   - 跳过"同向进入"：lines[i-2]→left 关系向上 且 left 向上（或向下对应）→ 该三线组只是趋势延续，非中枢。
2. 中枢区间：`ZG = min(前三线.高)`，`ZD = max(前三线.低)`（要求 ZD ≤ ZG，由基础检查保证有重叠）。
   方向 = 首线方向翻转。
3. 延伸：后续线与 [ZD,ZG] 关系**非缺口** → 并入中枢（`_添加虚线`，并重置第三买卖线）；
   **缺口**（向上缺口/向下缺口）→ 该线进入缓冲；若与中枢末线连续 → 成为**第三买卖线**候选。
4. 缓冲区 ≥3 线后，从中找新中枢（起始方向 = 当前中枢末线方向翻转）；找不到则弹出缓冲首线重试。
5. 中枢合法性回检（`_校验合法性`）：成员被序列淘汰/出现缺口/重叠不成立 → 裁剪，<3 线则废弃。

## 6. MACD（L1333+，L1420+ 增量计算）

- EMA：`alpha = 2/(N+1)`，首值种子=第一根收盘价（快12/慢26/信号9）；
  DEA_EMA 首值 = DIF；**MACD柱 = 2×(DIF−DEA)**（国内口径）。
- `K线.获取MACD(序列,始,终)`（L3112-3133）：区间内逐柱求和：
  `阳=Σ(柱≥0)`，`阴=Σ(柱<0)`，`总=阳+|阴|`。
- `MACD背驰`（L2405-2421）：离开段面积 < 进入段面积 → 背驰；
  方式=总 或按进入段方向取 阳(向上)/阴(向下)。

## 7. 买卖点（Rust 侧按标准规则实现；chan.py 该处为占位）

以**笔中枢**（≥3 笔重叠）为基准，在笔级别判定：

- **三买**：中枢结束后的 **1~2 笔**内出现「向下笔（回抽）最低点 > ZG」→ 该回抽笔终点处三买。
  中间的笔若为离开笔（向上离开 = 武端顶值 > ZG；向下离开 = 武端底值 < ZD）则继续看下一笔；
  若该笔既未离开也未构成回抽 → 走势仍在中枢内，直接终止。
  （v2 对齐 chan2zen/rust-chan `signals()`：在 `pole.index == pivot.end()` 后同时检查
  `poles[idx+1]` 与 `poles[idx+2]`。v1 只判中枢后第 1 笔，而结构上该笔通常是离开笔而非回抽笔，
  导致三买几乎不出信号。）
- **三卖**：镜像（反抽最高点 < ZD）；
- **二买**：某向下走势结束点为一买（或低点），随后向上笔再回落，回调低点不破前低 → 二买；
- **二卖**：镜像；
- **一买/一卖**：出现两个同向、区间不重叠（趋势）的笔中枢后，离开段相对进入段 MACD 面积背驰 →
  趋势背驰，向上趋势背驰=一卖，向下趋势背驰=一买；
- **盘整背驰**：中枢进入段 vs 离开段 MACD 面积背驰（离开段创新高/新低时）。

> 以上规则的判定序列均输出到夹具可比对的 per-bar 数组；与 chan.py 的差异（chan.py 无实现）
