# DLL 使用方法

## 1. 下载 DLL

从 [Releases](https://github.com/dororo42/chanlun-tdx/releases) 页面下载对应版本的 DLL：

- `chanlun_tdx_x64.dll` — 64 位通达信使用
- `chanlun_tdx_x86.dll` — 32 位通达信使用

> **位数匹配**：通达信 32 位版使用 x86 DLL，通达信 64 位版使用 x64 DLL。位数不匹配会导致加载失败。

## 2. 安装 DLL

1. 找到通达信安装目录（通常在 `C:\new_tdx\` 或 `C:\zd_pazq\` 等）
2. 进入子目录 `T0002\dlls\`（不存在则创建）
3. 将 DLL 文件复制到此目录，重命名为 `chanlun_tdx.dll`

```
C:\new_tdx\T0002\dlls\chanlun_tdx.dll
```

## 3. 绑定 DLL

1. 打开通达信
2. 功能 → 公式系统 → 公式管理器（或按 `Ctrl+F`）
3. 左侧展开 → **DLL 函数**
4. 点击 **绑定 DLL 函数**
5. 在 **DLL 绑定1** 位置浏览选择 `T0002\dlls\chanlun_tdx.dll`
6. 点击 **确定** — 状态栏应显示绑定成功

> 绑定到 slot 1 对应公式中的 `TDXDLL1(...)` 调用。如果 slot 1 已被占用，可绑定到 slot 2/3/4，但公式中的 `TDXDLL1` 要相应改为 `TDXDLL2` 等。

## 4. 导入公式

1. 公式管理器（Ctrl+F）中点击 **新建**
2. **主图叠加显示公式**：
   - 公式名称：`CLZT`（可自定）
   - 公式描述：缠论主图
   - 类型选择：**主图叠加**
   - 将 `formulas/缠论主图显示.txt` 内容粘贴到公式编辑区
   - 点击 **确认**
3. **条件选股公式**：
   - 公式名称：`CLXG`（可自定）
   - 公式描述：缠论选股
   - 类型选择：**条件选股**
   - 将 `formulas/缠论条件选股.txt` 内容粘贴到公式编辑区
   - 点击 **确认**

## 5. 使用

### 主图显示

打开任意个股 K 线图 → 输入公式名 `CLZT` 回车 → 缠论结构叠加在主图上

### 条件选股

功能 → 选股器 → 条件选股 → 选择 `CLXG` → 执行选股

> 选股遍历全市场约需 30 秒 - 3 分钟（取决于电脑性能）。

## 常见问题

**DLL 加载失败** → 检查位数是否匹配（32 位通达信用 x86 DLL）

**公式报错 TDXDLL1 未定义** → DLL 未绑定或绑定到非 slot 1

**图表无显示** → DLL 加载失败或公式类型未选"主图叠加"

**选股很慢** → 正常，每只股票都要全量重算管线
