# 通达信公式说明（v2.0）

三个公式**互相独立**（各自直接调用 DLL，无跨公式引用），可以只导入需要的那个。

| 文件 | 建议公式名 | 类型 | 作用 |
|---|---|---|---|
| `缠论主图显示.txt` | `CLZT` | 技术指标公式 → 主图叠加 | 笔 / 线段 / 中枢 / 买卖点 / 力度背驰 |
| `缠论条件选股.txt` | `CLXG` | 条件选股公式 | 二买/三买 + 力度背驰 + 未被破坏 |
| `缠论力度副图.txt` | `CLLD` | 技术指标公式 → 副图 | 笔·段的幅度/天数/力度 与背驰 |

> 公式内所有注释用 `{}` 包裹；**不要嵌套 `{}`**。

---

## 1. 主图公式（CLZT）

### 显示开关

文件顶部一组开关，改 `0` / `1` 即可：

| 开关 | 默认 | 说明 |
|---|---|---|
| `SHOW_FX` | 0 | 分型标记。数量多，默认关闭；打开后用 1/2 号箭头图标标顶底 |
| `SHOW_BI` | 1 | 笔：红=上笔、绿=下笔（`DOTLINE` 细虚线） |
| `SHOW_BZS` | 1 | 笔中枢：棕色上下沿轨线 + 起止竖框 + 中轴虚线 |
| `SHOW_XD` | 1 | 线段：橙=上段、蓝=下段（`LINETHICK2`） |
| `SHOW_XZS` | 0 | 线段中枢。与笔中枢经常重叠，默认关闭 |
| `SHOW_MMD` | 1 | 买卖点文字 |
| `SHOW_BC` | 1 | 背驰图标：31=笔力度背驰、32=段力度背驰、8=MACD 面积背驰 |

### 买卖点标记约定

| 标记 | 含义 | 颜色 |
|---|---|---|
| `1B` / `1S` | 一买（趋势背驰）/ 一卖 | 黄 |
| `2B` / `2S` | 二买 / 二卖 | 红 / 绿 |
| `3B` / `3S` | 三买 / 三卖 | 品红 / 浅蓝 |
| `2+3B` / `2+3S` | 二三买卖点**共振**（同一根 K 线同时成立，等价于 rust-chan 的 `SIG=23`） | 红 / 绿 |
| `背` | 盘整背驰 | 白 |

文字按级别向上/向下错位排列（共振 > 一买 > 二买 > 三买 依次靠近 K 线），避免 v1 那种全部堆在 `LOW*0.995` 附近糊成一坨。

### 中枢为什么改成「轨线 + 竖框」

v1 用 `STICKLINE(BZG>0,BZG,BZD,8,0)` —— 宽度 8 的**实心柱**把整个中枢区间涂满，K 线全被盖住。
v2 改为 rust-chan 的画法：

```
NOTEXT_BZG:IF(SHOW_BZS=1,BZG,DRAWNULL),COLORBROWN;   {上沿水平线}
NOTEXT_BZD:IF(SHOW_BZS=1,BZD,DRAWNULL),COLORBROWN;   {下沿水平线}
STICKLINE(SHOW_BZS=1 AND BZSE<>0,BZD,BZG,0,0),...;   {仅首/末根画竖线}
```

依赖 DLL 的 **mark 19（笔中枢起止）/ mark 20（线段中枢起止）**。想改回整段浅色填充，把 `STICKLINE` 那行换成文件里注释掉的 `...,0,1)` 版本。

### 已避开未来函数

rust-chan 用 `BACKSET(BISE=2, BARSLAST(BISE=-2)+1)` 反推中枢区间 —— `BACKSET` 是**未来函数**，每次新数据到来都会重绘历史。本公式改为由 DLL 的 mark 19/20 直接给出起止标记，历史不会变。

## 2. 力度背驰的算法（主图 / 选股 / 副图 共用同一段）

口径取自 rust-chan：**当前笔（段）与「上一个同向笔（段）」比较** —— 天数没有缩短、而幅度或力度变小，即为背驰。因为笔的方向天然交替，所以"上一个同向笔"就是**往回数第二个**端点。

```text
PBI1:=REF(BI,1)<>0;                            {上一根K线是不是笔端点}
NBI1:=BARSLAST(PBI1)+1;                        {到上一个端点的距离}
NBI2:=REF(BARSLAST(PBI1),NBI1)+NBI1+1;         {到上上个端点的距离}
BIOK:=BI<>0 AND NBI1>0 AND NBI1<BARSCOUNT(C) AND NBI2<BARSCOUNT(C);
笔幅度:=IF(BIOK,ABS(BIP-REF(BIP,NBI1)),DRAWNULL);
笔天数:=IF(BIOK,NBI1,DRAWNULL);
前笔幅度:=IF(BIOK,REF(笔幅度,NBI2),DRAWNULL);
前笔天数:=IF(BIOK,REF(笔天数,NBI2),DRAWNULL);
笔力度:=IF(BIOK,笔幅度/笔天数*100,DRAWNULL);
前笔力度:=IF(BIOK,前笔幅度/前笔天数*100,DRAWNULL);
笔背离:=BIOK AND 笔天数>=前笔天数 AND (笔幅度<前笔幅度 OR 笔力度<前笔力度);
```

几点说明：

- **为什么不用 rust-chan 的嵌套 `REF` 写法**。它用
  `REF(笔天数, REF(BARSLAST(FRAC=-1),BARSLAST(FRAC=1))+BARSLAST(FRAC=1))`
  定位上个同向笔，等价但可读性差、且依赖 `笔天数` 本身在目标 bar 有值。这里改成先算出"到上上个端点的距离" `NBI2`，再用 `REF(..., NBI2)` 取回前一笔，结果一致、层次清楚。
- **`NBI2` 末尾的 `+1` 不能省**。`BARSLAST(REF(E,1))` 在端点 bar 上给出的是"距离上一个端点 - 1"，补 1 后才是真实距离；少这个 1 会算成**前一笔**（反向笔）而不是**上一个同向笔**，背驰就判反了。
- **`SUM(...,0)` 与 `BARSLAST` 的坑**：`BARSLAST` 在"条件从未成立"时返回 0，与"今天刚成立"无法区分。选股公式里因此先用 `HASB2:=SUM(B2V,0)>0` 判断历史存在性，再判时效，否则会把"从没出过二买"的股票误判成"今天刚出二买"。
- `BIOK` 里的 `BARSCOUNT(C)` 上限是为了避免 `REF` 越界取到无效值（新股/早期 bar）。

## 3. 选股公式（CLXG）

### 默认口径

```
最近 N(=7) 根内出现「二买 或 三买」
  且 最近 N 根内出现过 笔力度背驰 或 段力度背驰
  且 该买点之后没有出现任何反向卖点（一卖/二卖/三卖）
  且 通过基础过滤（上市 >120 交易日、非 ST、非停牌/无数据）
```

三段判定的意义：

1. **时效（`DB2<N`）**——v1 用 `COUNT(B2,20)>0`，3 天前和 20 天前完全同等对待。
2. **未被破坏（`DS1>DB2`）**——v1 会把"20 天前出二买、之后已经走出一卖（趋势已终结）"的票照样选出来。现在要求买点之后没有反向卖点。
3. **力度背驰**——剔除"有买点但力度未衰竭"的追高票。

### 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `N` | 7 | 信号时效窗口（根），可改 3 / 5 / 10 |
| `MBS` | 120 | 最少上市交易日，排除次新股；设 0 关闭 |
| `FLT` | 1 | 基础过滤开关 |

> 若编译报「NAMELIKE 未定义」，删掉 `基础OK` 里的 `NOT(NAMELIKE('ST'))` 一段，或把 `FLT` 置 0。

### 备选口径

文件底部列了 7 种备选，注释掉 `XG:` 那行、取消目标行注释即可：

| 口径 | 适用 |
|---|---|
| 仅三买 | 趋势延续，信号最少最干净 |
| 二买/三买（不加背驰） | 宽口径，票多 |
| 二三买共振（当根） | 最强买点，票极少 |
| 力度背驰必须与买点同根 | 最严 |
| 一买 + 盘整背驰 | 抄底，风险最高 |
| 一二三买全口径 | 最宽 |
| 仅三买（等价写法） | 便于继续扩展 |

## 4. 力度副图（CLLD）

- 画线：`笔力度`（品红 `LINETHICK2`）、`段力度`（橙 `LINETHICK2`）、`前笔力度`（灰虚）、`前段力度`（棕虚）、`零轴`（灰虚）。
- 背驰处打图标：31=笔力度背驰、32=段力度背驰。
- `笔幅度 / 笔天数 / 段幅度 / 段天数` 用 `NODRAW`，不画线但在**数据窗口**可见，方便逐笔核对。

力度 = 幅度 / 天数 × 100，已做时间归一，笔与段的数值量级可比。

## 5. 与 chan2zen/rust-chan 的口径对照

**可以搬（已搬）**

| rust-chan 做法 | 本项目落地 |
|---|---|
| 中枢画「上下轨 + 起止框」，不用实心块 | 主图公式第 6 节（依赖新增 mark 19/20） |
| 笔用 `DOTLINE`、段用 `LINETHICK2` 分层 | 主图公式第 5/7 节 |
| 力度背驰（幅/天数/力度）用公式算，不依赖 MACD | 三个公式共用的那段 |
| 三买判定看中枢结束后的后 1~2 笔 | `src/chan.rs` `detect_mmds` |
| 买卖点共振信号（`SIG=23`） | 主图 `2+3B` / `2+3S` |
| 选股用 `BARSLAST` 比信号先后，而不是 `COUNT` 计数 | 选股公式第 3 节 |
| 指标公式 + 主图 + 选股 分层组织 | 三个公式文件 |

**不能搬（核心算法不同源）**

| rust-chan | 本项目 | 原因 |
|---|---|---|
| 单函数 `zigzag` + mode 位编码（千位笔模式/十位中枢级别/百位输出类型） | 20 个 mark 的逐 bar 输出 | DLL 接口层完全不同，公式调用形式无法通用 |
| `Pole` 统一表示笔/段/趋势端点，带 `segmented` / `trended` 标志 | 分型 → 笔端点 → 线段 三套独立结构 | 要引入"统一极点"需重写算法层 |
| 中阴段（`intermediate`，未完成段的合并极点） | 无此概念 | 同上 |
| 强分型 `FXX=-2/2`、弱分型 `-1/1` | 只有顶/底分型，无强弱 | 算法层没有强弱判定 |
| `Pivot.extended` 中枢扩张（ZG/ZD 输出负值） | `Pivot` 结构体无 `extended` 字段 | 无法输出 |
| `BACKSET` 反推中枢区间 | —— | **刻意不搬**：未来函数会重绘历史 |

> 结论：借用的是**呈现层与判定技巧**，结构数据仍然完全由本项目自己的 DLL 提供。

## 6. 已知边界

- **分型/笔/中枢/MACD 与 chan.py 100% 对齐**（`cargo test --test parity` 守护）；**线段**为结构不变量验证（chan.py 的流式修正难以在批处理里完全复刻，偏差记录在内部 REPORT）。
- **买卖点没有 Python 对照物**（chan.py 的 `识别买卖点` 是 `pass` 占位），因此 v2 对三买/三卖判定窗口的修改不影响 parity，属于本项目自主口径。
- **最后一个分型/笔端点是"未确认"的**：缠论流式语义下，序列末端的分型可能被后续 K 线改写。这与 DLL 无关，是缠论本身的特性，看盘时对最右侧结构保留余地即可。
- **条件选股里的 DLL 调用**：每只股票触发一次全量重算（毫秒级），10 次 mark 调用共享同一份缓存，不会重复计算。
