{通达信·缠论条件选股公式}
{ DLL: chanlun_tdx.dll → 绑定到 TDXDLL1 }
{ 公式类型: 条件选股公式 }
{ 用法: 公式管理器 → 新建 → 类型选"条件选股" → 粘贴 → 确认 }
{      然后选股器中选用本公式 → 执行选股 }

{=== 买卖点信号 ===}
B1:=TDXDLL1(15,HIGH,LOW,CLOSE)>0;
B2:=TDXDLL1(13,HIGH,LOW,CLOSE)>0;
B3:=TDXDLL1(11,HIGH,LOW,CLOSE)>0;
PZ:=TDXDLL1(17,HIGH,LOW,CLOSE)>0;

{--- 信号窗口 N = 最近N根K线内出现信号即选出 ---}
{默认: 二买或三买（稳健型）}
XG:COUNT(B2,20)>0 OR COUNT(B3,20)>0;

{扩展条件（按需替换上方XG行后取消注释）:}

{条件A: 三买——趋势延续型}
{XG:COUNT(B3,20)>0;}

{条件B: 二买——回调企稳型}
{XG:COUNT(B2,20)>0;}

{条件C: 一买——抄底型（风险较高）}
{XG:COUNT(B1,20)>0;}

{条件D: 一买+盘整背驰共振（强信号）}
{XG:COUNT(B1,20)>0 AND COUNT(PZ,20)>0;}

{条件E: 全部买入信号（宽口径）}
{XG:COUNT(B1,20)>0 OR COUNT(B2,20)>0 OR COUNT(B3,20)>0;}
